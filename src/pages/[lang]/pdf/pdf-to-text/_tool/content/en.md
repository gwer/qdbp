## How to use

Choose a PDF and the text of all its pages appears in the box below. Copy it with the “Copy” button or save it as a TXT file. The “Page numbers” switch adds a line with the page number before each page's text. That helps when you later need to find a passage in the original.

## How it works

In a PDF created from Word, a browser or another program, text is stored as text: the letters, their font and position on the page. The tool reads it page by page with the same engine that's built into Firefox (pdf.js) and puts it together into lines in the order it's stored in the file. The file is never uploaded.

Formatting is lost along the way: bold type, tables and columns become plain lines. In documents with two columns or a complex layout, the line order may differ from the order a person would read them in.

## FAQ

**Why isn't any text extracted?** Most likely it's a scan: the page is stored as a picture, and the file has no letters, only pixels. Getting text out of a scan takes text recognition (OCR), which this tool doesn't do.

**Why do I get strange symbols instead of letters?** Some PDFs embed a font without a table that maps its glyphs to letters. Such text looks right on screen but copies as gibberish — from Acrobat too. Only text recognition helps.

**How do I save pages as images?** Use the [PDF to JPG converter](/en/pdf/pdf-to-jpg/).

**Need to count words or characters?** Paste the text into the [word and character counter](/en/text/word-counter/).
