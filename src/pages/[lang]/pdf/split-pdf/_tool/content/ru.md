## Как пользоваться

Выберите PDF — появятся миниатюры всех страниц. Затем выберите способ:

- **По N страниц** — файл режется на равные части. При N = 1 каждая страница станет отдельным PDF, при N = 2 — по две страницы и так далее. Последняя часть может быть короче.
- **По диапазонам** — перечислите части через запятую: `1-3, 4-10, 11-` даст три файла. Диапазоны могут пересекаться, а `5-1` соберёт страницы в обратном порядке.
- **Выбрать страницы** — отметьте нужные страницы щелчком и получите их одним файлом или каждую отдельно. Так удобно извлечь из документа несколько страниц, например скан паспорта из пакета документов.

На миниатюрах номер в углу показывает, в какой файл попадёт страница, бледные страницы не попадут никуда. Нажмите «Разделить» и скачайте части по одной или все сразу архивом ZIP.

## Как это работает

Страницы копируются в новые файлы как есть, без пересжатия: текст остаётся текстом, сканы не теряют в качестве. Шрифты и картинки, общие для нескольких страниц, попадают в каждую часть, где они нужны, поэтому сумма размеров частей бывает больше исходного файла.

Файл не загружается на сервер: разделение идёт в браузере. Если PDF защищён паролем на открытие, его спросят сразу после выбора файла. Части сохраняются без пароля.

## Частые вопросы

**Как удалить из PDF лишние страницы?** Можно выбрать нужные страницы здесь и сохранить их одним файлом. Удобнее — в инструменте [«Удаление страниц из PDF»](/ru/pdf/organize-pdf/): там лишние страницы удаляются кнопкой, а оставшиеся можно переставить и повернуть.

**Почему пропали закладки и ссылки на другие страницы?** Части собираются из страниц заново, а оглавление и внутренние ссылки описывают исходный документ целиком. Ссылки на сайты сохраняются.

**Как собрать части обратно?** В инструменте [«Объединение PDF»](/ru/pdf/merge-pdf/) — в любом порядке.
