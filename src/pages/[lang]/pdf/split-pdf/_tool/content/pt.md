## Como usar

Escolha um PDF — aparecem as miniaturas de todas as páginas. Depois escolha o modo:

- **A cada N páginas** — o arquivo é dividido em partes iguais. Com N = 1, cada página vira um PDF separado; com N = 2, duas páginas por arquivo, e assim por diante. A última parte pode ser menor.
- **Por intervalos** — liste as partes separadas por vírgula: `1-3, 4-10, 11-` gera três arquivos. Os intervalos podem se sobrepor, e `5-1` junta as páginas em ordem inversa.
- **Escolher páginas** — marque as páginas com um clique e receba-as em um só arquivo ou cada uma separada. É prático para tirar algumas páginas de um documento, como a cópia do RG de um pacote de documentos.

Nas miniaturas, o número no canto mostra em qual arquivo a página vai entrar; as páginas apagadas não entram em nenhum. Clique em "Dividir" e baixe as partes uma por uma ou todas juntas num ZIP.

## Como funciona

As páginas são copiadas para os novos arquivos como estão, sem nova compressão: o texto continua texto, e as digitalizações não perdem qualidade. Fontes e imagens compartilhadas por várias páginas entram em cada parte que precisa delas, por isso a soma dos tamanhos das partes pode passar do tamanho do arquivo original.

O arquivo não é enviado a nenhum servidor: a divisão acontece no navegador. Se o PDF tiver senha para abrir, ela é pedida logo depois de escolher o arquivo. As partes são salvas sem senha.

## Perguntas frequentes

**Como excluir páginas que sobram num PDF?** Dá para escolher aqui as páginas que você quer e salvá-las em um só arquivo. É mais prático no [organizador de páginas PDF](/pt/pdf/organize-pdf/): lá as páginas extras são excluídas com um botão, e as restantes podem ser reordenadas e giradas.

**Por que sumiram os marcadores e os links para outras páginas?** As partes são montadas de novo a partir das páginas, e o sumário e os links internos descrevem o documento original inteiro. Os links para sites são mantidos.

**Como juntar as partes de novo?** Na [junção de PDF](/pt/pdf/merge-pdf/) — em qualquer ordem.
