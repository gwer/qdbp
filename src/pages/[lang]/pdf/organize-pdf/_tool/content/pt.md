## Como usar

Escolha um PDF — aparecem as miniaturas de todas as páginas. Abaixo de cada miniatura há botões:

- a lixeira exclui a página. Ela fica no lugar, apagada, e pode ser restaurada pelo mesmo botão;
- as setas circulares giram a página 90° para a esquerda ou para a direita;
- as setas angulares movem a página uma posição para trás ou para frente.

É mais prático mudar a ordem arrastando: pegue a miniatura e solte-a no novo lugar. Os botões "Todas para a esquerda" e "Todas para a direita" giram o documento inteiro de uma vez, por exemplo quando a digitalização saiu deitada.

Quando tudo estiver pronto, clique em "Salvar PDF" e baixe o arquivo. O arquivo original não muda.

## Como funciona

A edição é feita no próprio documento, não numa cópia. Por isso fica tudo o que não pertence às páginas excluídas: sumário (marcadores), campos preenchíveis, propriedades do documento, arquivos anexados. O conteúdo das páginas não é comprimido de novo, e a qualidade não muda.

A rotação é gravada na propriedade da página, como fazem o Acrobat e outros editores. Não é salvar a imagem de novo, então dá para girar a página quantas vezes quiser sem perdas.

O arquivo é processado no navegador e não é enviado a nenhum servidor. Se o PDF tiver senha para abrir, digite a senha primeiro. O arquivo salvo já fica sem senha.

## Perguntas frequentes

**Por que o arquivo quase não diminuiu, se excluí muitas páginas?** Fontes e imagens muitas vezes são compartilhadas pelo documento todo e ficam enquanto pelo menos uma página as usar. Para reduzir bem o peso, [comprima o PDF](/pt/pdf/compress-pdf/).

**Como tirar algumas páginas para um arquivo separado?** Para isso existe o [divisor de PDF](/pt/pdf/split-pdf/) com o modo "Escolher páginas".

**Dá para adicionar páginas de outro arquivo?** Primeiro junte os arquivos na [junção de PDF](/pt/pdf/merge-pdf/) e depois organize as páginas aqui.
