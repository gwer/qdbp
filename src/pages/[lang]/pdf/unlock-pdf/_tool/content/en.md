## How to use

Choose a PDF. If it has a password to open it, enter the password — the tool checks right away whether it's correct. Then click “Remove protection” and download the copy: it opens without a password and has no restrictions on printing, copying or editing. The original file doesn't change.

If there's no password to open the file but it won't let you print or copy text, those are owner restrictions. You don't need a password to remove them: just choose the file and save a copy.

## How it works

The file is decrypted with the password you entered and saved again, this time without encryption. The content doesn't change: text, images, bookmarks and form fields stay as they were.

Everything happens in your browser. Neither the file nor the password is sent to a server.

## FAQ

**I forgot the password. Can I still open the file?** No. This tool removes protection only when you know the password. Without it the content is encrypted, and guessing a password for modern encryption (AES) is practically impossible. Try to find the password where the file came from: in the bank's email, in the contract, or ask the sender.

**My bank sends statements with a password. How do I remove it so I don't have to type it every time?** The password is often your date of birth or the last digits of the account number — the rule is stated in the email. Enter the password here and save a copy without it. Keep that copy as carefully as the original.

**Whose files can I unlock?** Remove protection from your own documents and from documents sent to you to work with. For anyone else's files, ask the owner first: restrictions are usually there for a reason.

**How do I put a password back, or on another file?** With the [PDF password protector](/en/pdf/protect-pdf/).
