## Как пользоваться

Вставьте JSON — он сразу отформатируется с отступами. Если в JSON есть ошибка, калькулятор покажет, в какой строке и в каком столбце она находится. Режимы:

- **Отступ 2 или 4 пробела, табуляция** — для чтения и вставки в код;
- **Сортировать ключи** — ключи объектов по алфавиту на всех уровнях, удобно сравнивать два JSON;
- **Минифицировать** — всё в одну строку без лишних пробелов, для передачи по сети и в конфигах.

Данные обрабатываются в браузере и никуда не отправляются — можно проверять JSON с токенами и личными данными.

## Частые ошибки в JSON

- **Одинарные кавычки:** `{'a': 1}` — в JSON строки и ключи только в двойных кавычках.
- **Запятая после последнего элемента:** `[1, 2,]` — в JSON так нельзя (в JavaScript можно).
- **Ключи без кавычек:** `{a: 1}` — это JavaScript, а не JSON.
- **Комментарии** `//` и `/* */` — в стандартном JSON их нет.
- **Ведущий ноль** `01`, `NaN`, `undefined` — недопустимые значения.

## Частые вопросы

**Почему кириллица не превращается в `а…`?** Экранировать не-ASCII символы не обязательно: JSON по стандарту записывается в UTF-8.

**Есть ли ограничение на размер?** Нет, кроме памяти устройства; файлы в несколько мегабайт обрабатываются за доли секунды.

Чтобы закодировать JSON для URL или Base64, используйте [URL-кодирование](/ru/security/url-encode/) или [Base64](/ru/security/base64/).
