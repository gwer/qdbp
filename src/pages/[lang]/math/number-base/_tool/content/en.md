## How to use

Enter a whole number and choose which base it's written in. You'll instantly see it in binary, octal, decimal and hexadecimal, plus any base from 2 to 36.

Letter case doesn't matter, spaces and underscores between digits are ignored, and the `0b`, `0o` and `0x` prefixes are recognized. Numbers can be any length — no precision is lost.

## How it works

In base N, each digit is worth N times more than the digit to its right. For example, binary 1011 = 1·8 + 0·4 + 1·2 + 1·1 = 11. Bases above 10 use letters as digits: A = 10, B = 11, … F = 15, … Z = 35.

## Examples

- 255 = **11111111** (binary) = **377** (octal) = **FF** (hex).
- 2026 = **11111101010** = **3752** = **7EA**.
- Hex FFFFFFFF = **4294967295**, the largest unsigned 32-bit number.

## FAQ

**Can I convert fractions?** No, the converter works with whole numbers, including negative ones.

**What is base 36 used for?** Short IDs and URL slugs: it uses all ten digits and all 26 Latin letters.
