## So funktioniert der Umrechner

Geben Sie eine normale Zahl ein, um sie in römischen Zahlen zu sehen, oder eine römische Zahl (groß oder klein geschrieben), um ihren Wert zu erhalten. Die Richtung wird automatisch erkannt.

## So schreibt man römische Zahlen

Die Zeichen sind I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 und M = 1000. Normalerweise stehen sie vom größten zum kleinsten und werden addiert: XV = 15. Steht ein kleineres Zeichen vor einem größeren, wird es abgezogen: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900.

Kein Zeichen steht mehr als dreimal hintereinander, deshalb reicht die übliche Schreibweise von 1 bis 3999.

## Beispiele

- 2026 = **MMXXVI**.
- 1994 = **MCMXCIV**.
- 3999 = **MMMCMXCIX**, die größte Zahl in der üblichen Schreibweise.
- XIV = **14**, XL = **40**.

## Häufige Fragen

**Warum wird IIII nicht akzeptiert?** Das ist eine nicht standardmäßige Schreibweise (manchmal auf Zifferblättern zu sehen). Der Umrechner prüft die übliche Form: 4 = IV.

**Gibt es bei römischen Zahlen eine Null?** Nein – es gibt weder die Null noch negative Zahlen.
