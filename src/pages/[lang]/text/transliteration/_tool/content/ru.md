## Как пользоваться

Вставьте текст на русском и выберите систему транслитерации — латинский вариант появится сразу.

## Системы

**Загранпаспорт (ICAO).** По этим правилам МИД записывает имена и фамилии в загранпаспортах с 2017 года (международный стандарт ICAO Doc 9303). Особенности: Х → KH, Ц → TS, Щ → SHCH, Ю → IU, Я → IA, Й → I, Ъ → IE, Ь не передаётся.

- Щукин Юрий → **Shchukin Iurii**
- Ёлкина Наталья → **Elkina Natalia**
- Подъячев → **Podieiachev**

**ГОСТ 7.79-2000, система Б.** Используется в библиографии, научных публикациях, на сайтах госорганов. Буквы передаются однозначно и обратимо: Ё → YO, Й → J, Х → X, Щ → SHH, Ы → Y\`, Ь → \`, Ц → C перед е, и, ы, й и CZ в остальных случаях.

- Цирк → **Cirk**, Цапля → **Czaplya**, Юрий → **Yurij**

**Для ссылок (slug).** Только строчная латиница, цифры и дефисы — для адресов страниц, имён файлов и тегов: «Кредитный калькулятор» → `kreditnyy-kalkulyator`.

## Частые вопросы

**Как написать фамилию латиницей для билета или визы?** Так же, как в загранпаспорте, — выберите режим «Загранпаспорт». Если в паспорте уже есть другое написание, используйте его: важно совпадение с документом.

**Почему в старом паспорте фамилия записана иначе?** Правила менялись: до 2010 года, например, Ю передавали как YU, а с 2010 по 2017 год Ц — как TC. Новые правила применяются при выдаче нового паспорта; по заявлению можно сохранить прежнее написание.

**Можно ли перевести латиницу обратно в кириллицу?** Однозначно — только для ГОСТ 7.79 (система Б); правила загранпаспорта необратимы (Е и Э, И и Й дают одинаковые буквы).

Сменить регистр текста можно в [конвертере регистра](/ru/text/case-converter/).
