## Como usar

Para traduzir um texto para Morse, escolha "Para Morse" e digite — letras (inclusive Ç), números e pontuação são aceitos. Para decifrar, escolha "De Morse" e cole os pontos e traços.

As letras são separadas por espaço e as palavras por uma barra `/`. Também dá para colar `·` e `—` no lugar de pontos e traços.

## Exemplos

- SOS → `... --- ...`
- Olá → `--- .-.. .--.-`

## Perguntas frequentes

**Por que SOS é o sinal de socorro?** Não significa nada em especial: três pontos, três traços e três pontos é fácil de transmitir e difícil de confundir.

**Qual é o ritmo do Morse de verdade?** Um traço dura três pontos; entre letras há uma pausa de três pontos e entre palavras, de sete.

**Código Morse é criptografia?** Não, é um código público, sem chave. Para criptografar de forma simples, use a [cifra de César](/pt/security/caesar-cipher/).
