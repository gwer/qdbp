## So funktioniert's

Um Text in Morsecode zu übersetzen, „In Morse“ wählen und eingeben – Buchstaben mit Umlauten, Ziffern und Satzzeichen werden unterstützt. Zum Entschlüsseln „Aus Morse“ wählen und Punkte und Striche einfügen.

Buchstaben werden durch Leerzeichen getrennt, Wörter durch einen Schrägstrich `/`. Statt Punkt und Strich können Sie auch `·` und `—` einfügen.

## Beispiele

- SOS → `... --- ...`
- Hallo → `.... .- .-.. .-.. ---`

## Häufige Fragen

**Warum ist SOS das Notsignal?** Es steht für nichts Bestimmtes – drei kurz, drei lang, drei kurz ist einfach leicht zu senden und kaum zu verwechseln.

**Wie ist der Rhythmus beim echten Morsen?** Ein Strich dauert so lang wie drei Punkte; zwischen Buchstaben liegt eine Pause von drei Punkten, zwischen Wörtern von sieben.

**Ist Morsecode eine Verschlüsselung?** Nein, ein öffentlicher Code ohne Schlüssel. Für einfache Verschlüsselung gibt es die [Caesar-Verschlüsselung](/de/security/caesar-cipher/).
