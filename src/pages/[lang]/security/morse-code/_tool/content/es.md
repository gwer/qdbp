## Cómo usarlo

Para traducir un texto a morse, elige «A morse» y escribe: se admiten letras (incluida la Ñ), números y signos de puntuación. Para descifrar, elige «Desde morse» y pega los puntos y rayas.

El botón «Escuchar» reproduce el código a 18 palabras por minuto con un tono de 600 Hz, como se aprende Morse de oído.

Las letras se separan con un espacio y las palabras con una barra `/`. También puedes pegar `·` y `—` en lugar de puntos y rayas.

## Ejemplos

- SOS → `... --- ...`
- Hola → `.... --- .-.. .-`

## Preguntas frecuentes

**¿Por qué SOS es la señal de socorro?** No significa nada en concreto: tres puntos, tres rayas y tres puntos es fácil de enviar y difícil de confundir.

**¿Cómo se marca el ritmo en morse real?** Una raya dura como tres puntos; entre letras hay una pausa de tres puntos y entre palabras, de siete.

**¿El morse es un cifrado?** No, es un código público sin clave. Para cifrar de forma sencilla, prueba el [cifrado César](/es/security/caesar-cipher/).
