## Как пользоваться

Выберите пол и введите рост — калькулятор покажет идеальный вес по четырём известным формулам и диапазон нормального веса по индексу массы тела.

## Формулы

Все четыре формулы придуманы для дюймов: берут вес для роста 5 футов (152,4 см) и прибавляют по нескольку килограммов на каждый дюйм (2,54 см) сверх него.

| Формула | Мужчины | Женщины |
|---|---|---|
| Девайн (1974) | 50 + 2,3 кг на дюйм | 45,5 + 2,3 кг на дюйм |
| Робинсон (1983) | 52 + 1,9 кг | 49 + 1,7 кг |
| Миллер (1983) | 56,2 + 1,41 кг | 53,1 + 1,36 кг |
| Хамви (1964) | 48 + 2,7 кг | 45,5 + 2,2 кг |

Например, мужчина ростом 178 см (≈ 70 дюймов, 10 сверх 5 футов): по Девайну 50 + 2,3 × 10 = **73 кг**.

## Какой формуле верить

Ни одной в отдельности. Формулу Девайна создавали для дозировки лекарств, а не для оценки фигуры, остальные — её уточнения. Разброс между ними и есть честный ответ: «идеальный вес» — это диапазон, а не точка. Шире всех — диапазон по ИМТ (18,5–24,9), его использует ВОЗ.

## Частые вопросы

**Почему формулы не учитывают возраст и телосложение?** Они очень простые и опираются только на рост. Люди с крупной костью или большой мышечной массой весят больше без вреда для здоровья — тогда полезнее оценить [процент жира](/ru/health/body-fat/).

**Подходит ли расчёт для роста ниже 152 см?** Формулы для такого роста работают плохо: из базового веса вычитаются килограммы, и результат получается заниженным. Ориентируйтесь на диапазон по ИМТ.

Результат — ориентир, а не медицинская рекомендация. Проверить текущий вес можно в [калькуляторе ИМТ](/ru/health/bmi/).
