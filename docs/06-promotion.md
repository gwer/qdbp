# 06. Продвижение

Основной канал — органический поиск (ожидаемо 80–90% трафика). Всё остальное нужно в основном ради ссылок, брендовых сигналов и первичного трафика, пока Google присматривается к новому домену.

## 1. Техническое SEO (с первого дня)
- Всё из [03, раздел 7](03-tech.md#7-seo-реализация): canonical, hreflang, sitemap по языкам, JSON-LD, быстрые страницы.
- Search Console, Bing Webmaster Tools (через него же — DuckDuckGo, Yahoo, частично ChatGPT search), Яндекс Вебмастер (ru), Naver Search Advisor (если ko).
- Ежемесячный аудит: покрытие индекса, «Обнаружено, не проиндексировано» (сигнал низкой ценности — углублять или объединять страницы), CWV, ошибки hreflang.

## 2. Контентная стратегия
- **Кластеры, а не россыпь.** Запускать кластер целиком (10–20 связанных инструментов + хаб категории), чтобы сразу показать тематическую полноту.
- **Страница инструмента = инструмент + ответ.** Над сгибом — инструмент. Ниже — объяснение метода, примеры с числами, FAQ по реальным запросам («People also ask», подсказки).
- **E-E-A-T:** страница «О нас» с реальными людьми, автор/проверяющий у финансовых и медицинских инструментов, источники формул (ГОСТ, СНиП, ВОЗ, ЦБ, IRS), дата последней проверки.
- **Хабы-гайды** (P2): «Как рассчитать ипотеку: полное руководство» со встроенными калькуляторами. Собирают информационный трафик и ссылки.
- **Сезонные пики:** налоги (весна), Новый год/праздники (обратный отсчёт), Thanksgiving (индейка), отпуска (отпускные), учебный год (GPA). Публиковать за 1–2 месяца до пика.

## 3. Ссылки (главная проблема нового сайта)
Без ссылок новый домен в конкурентных темах не поднимется. Белые способы, по эффективности:

1. **Флагманские «вау»-инструменты** (приватная обработка изображений/PDF, удаление фона в браузере, хороший генератор QR) → Show HN, Product Hunt, Reddit (r/webdev, r/InternetIsBeautiful, r/privacy, тематические сабреддиты), Habr/vc.ru для RU. Один удачный запуск даёт десятки ссылок.
2. **Встраиваемые виджеты.** `<iframe>`/скрипт калькулятора для блогов, сайтов риелторов, строительных магазинов, школ — с атрибуцией. Масштабируемый органический линкбилдинг (атрибуцию делать не спамной, с естественным анкором, иначе риск санкций за link schemes).
3. **Ресурсные страницы.** Школы, университеты, библиотеки, профильные сообщества часто ведут «полезные ссылки» — писать им лично, только с действительно подходящими инструментами.
4. **Открытый код.** Выложить на GitHub движок формул или отдельные библиотеки (например, валидаторы национальных ID, база плотностей продуктов) — ссылки от разработчиков, звёзды, упоминания.
5. **Данные и исследования.** Раз в квартал — небольшой оригинальный датасет/исследование на основе инструментов («Сколько стоит ремонт ванной в 2027 в 10 странах») → PR, журналисты. Требует усилий, но даёт самые сильные ссылки.
6. **Экспертные комментарии для СМИ** (Qwoted, Featured, SourceBottle, Pressfeed для RU) — по финансовым/бытовым темам.
7. **Тематические форумы и Q&A** (FORUMHOUSE для стройки, кулинарные форумы, Stack Overflow для dev) — только отвечая по делу, без спама.

**Не делать:** покупку ссылок, PBN, обмен ссылками в промышленных масштабах, «гостевые посты» на ферме сайтов. Сайт с 1 000+ страниц и рекламой — лёгкая цель для ручных санкций.

## 4. Другие каналы
- **Pinterest** — неожиданно хорош для кухни, ремонта, размеров одежды, календарей, шпаргалок. Пины-инфографики с таблицами → ссылка на инструмент. Работает в EN/ES/PT/DE.
- **YouTube Shorts / TikTok** — «Как посчитать плитку за 30 секунд» — низкий приоритет, только если появится ресурс.
- **Telegram/VK** для RU — канал с подборками инструментов, слабый приоритет.
- **Каталоги** (AlternativeTo, Futurepedia-подобные для dev/image-tools, «awesome-*» списки на GitHub) — быстрые и бесплатные ссылки.
- **Email/рассылки** — не на старте.

## 5. Видимость в AI-поиске
- ChatGPT search, Perplexity, Google AI Mode цитируют источники. Шанс попасть в цитаты выше у страниц с чёткими определениями, формулами, таблицами и короткими прямыми ответами под заголовками.
- **Решение по ботам (обсудить):** рекомендую разрешить поисковых ботов AI-сервисов (OAI-SearchBot, PerplexityBot, ChatGPT-User, Google-Extended не блокировать без причины), а обучающих (GPTBot, CCBot и т. п.) — по вкусу. Блокировка не вернёт трафик, но лишит цитирований.
- Для простых запросов AI отвечает сам — но для сложных («рассчитай ипотеку с досрочными погашениями») всё чаще отправляет к инструменту. Наша цель — быть этим инструментом.

## 6. Поведенческие и UX-сигналы
- Мгновенный результат, понятные значения по умолчанию, отсутствие агрессивной рекламы над инструментом.
- Поделиться результатом ссылкой (состояние в URL) — естественные ссылки из мессенджеров и форумов.
- Избранное/история в `localStorage` и PWA — повторные визиты и брендовый поиск.
- Брендовые запросы («<бренд> калькулятор ипотеки») — сильный долгосрочный сигнал. Короткое запоминающееся имя помогает.

## 7. Метрики и ритм
| Метрика | Источник | Частота |
|---|---|---|
| Проиндексированные страницы / покрытие | GSC | неделя |
| Показы, клики, CTR, средняя позиция по кластерам и языкам | GSC | неделя |
| Ссылающиеся домены | Ahrefs/Semrush (платно) или бесплатные Ahrefs Webmaster Tools | месяц |
| CWV (полевые данные) | GSC / CrUX | месяц |
| Визиты, страницы, источники, страны | Cloudflare Web Analytics | неделя |
| RPM, доход по языкам/странам | рекламная сеть | месяц |

Ежемесячный ритуал: 1) найти страницы с показами и низким CTR → переписать title/description; 2) найти запросы на позициях 8–20 → усилить страницу контентом и внутренними ссылками; 3) найти «соседние» запросы без страницы → кандидаты на новые инструменты.
