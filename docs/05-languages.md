# 05. Языки

## Критерии выбора
Для каждого языка оцениваем:
1. **Объём поискового спроса** на инструменты (число пользователей интернета на языке × доля, которая ищет на родном языке).
2. **Конкуренция** в выдаче (насколько слабы локальные сайты и переводы гигантов).
3. **RPM рекламы** в странах языка (US/UK/CA/AU/DE/CH/NL/скандинавы — высокий; ES/FR/IT/JP — средний; LatAm, Восточная Европа, Турция, ЮВА, Индия — низкий).
4. **Стоимость адаптации**: RTL, сложная плюрализация, нестандартные шрифты, отдельный поисковик (Baidu, Naver).
5. **Возможность монетизации** вообще (санкции, доступность рекламных сетей).

Справочно (W3Techs, 2026): доля сайтов по языкам контента — EN ~49,5%, ES ~6%, DE ~6%, JA ~5%, FR ~4,6%, PT ~4,1%, RU ~3,5%. Доля пользователей при этом сильно иная: на китайском, хинди, арабском, индонезийском людей много, контента мало — это и возможность, и признак низкого RPM.

## Правила локализации
- Язык включается для инструмента **только при полном переводе** (см. [03](03-tech.md#6-i18n)). Нормально и даже полезно, что часть инструментов есть только на части языков — см. [03, раздел 6.2](03-tech.md#62-неполное-покрытие-языков). Язык открывается на сайте при ~20–30 переведённых инструментах.
- Не все инструменты переводить на все языки: сначала смотреть, есть ли спрос на этом языке (локальные налоги DE не нужны на японском).
- Адаптация примеров: валюта, единицы, формат дат, местные реалии (в примерах ипотеки — реалистичные для страны суммы и ставки).
- Языковые варианты (en-US/en-GB, es-ES/es-MX, pt-BR/pt-PT) — на старте **не** разделять, писать нейтрально и давать выбор единиц/валют в самом инструменте. Разделять только если данные покажут смысл.
- Для каждого языка волны 1 — хотя бы выборочная вычитка носителем (ориентир: $30–80/час фриланс, или $0,03–0,08/слово). Машинный перевод без вычитки — допустимо для длинного хвоста, но со сниженной уверенностью.

## Стоимость языка (порядок)
- Типовая страница инструмента: ~400–900 слов (UI + контент).
- 100 инструментов × 700 слов ≈ 70 тыс. слов на язык.
- LLM-перевод: копейки (единицы долларов). Вычитка носителем всего объёма: ~$2–5 тыс. на язык; выборочная (топ-20% страниц по трафику): ~$400–1 000.
- Рекомендация: LLM-перевод с глоссарием + вычитка топ-страниц и всех YMYL (финансы, здоровье).
