# Аудит: text, dev, security, images

Субагент читал код и ru.json. Вживую открывал wordcounter.net, base64decode.org, jsonformatter.org; regex101, jwt.io, squoosh, tinypng, iloveimg, dcode — по памяти.

## Общее
- TextConverter (case, line-tools, transliteration, json, base64, url, morse): нет кнопки «Результат → в поле ввода» (цепочки действий, кодировать↔декодировать). Высокий / низкая.
- Нет примера/плейсхолдера (кроме JSON). Средний / низкая.

## text
- **word-counter** — время чтения и речи (В); частотность слов (С); строки, уникальные слова (Н).
- **case-converter** — CONSTANT_CASE, dot.case (Н).
- **line-tools** — одно действие за раз, нужна цепочка (В); статистика «было N → стало M» (С); перемешать/нумерация/префикс (Н).
- **lorem-ipsum** — поле количества `type="number"` нарушает правило проекта (В); русская «рыба» (Н).
- **transliteration** — обратное направление (Н).

## dev
- **json-formatter** — «мягкий» ремонт (висячие запятые, одинарные кавычки, комментарии) (С); файл (Н); дерево (Н).
- **jwt-decoder** — проверка подписи HS* через WebCrypto (С); раскраска частей (Н).
- **regex-tester** — строка:столбец (Н); шпаргалка (Н).
- **subnet-calculator** — разбиение на подсети (С); двоичный вид (Н); IPv6 (отложить).
- **text-diff** — игнорировать пробелы/регистр (С); файлы (Н).
- **color-converter** — контраст «мой текст на моём фоне» (С); оттенки (Н).

## security
- **base64** — в description обещан URL-safe, кодирование его не умеет (В); файлы — хотя бы ссылка на image-to-base64 (С).
- **url-encode** — нет режима «ссылка целиком» (encodeURI) (В); разбор query в таблицу (Н).
- **hash** — хеш файла (В); сравнение с ожидаемым (С); HMAC (Н).
- **caesar-cipher** — перебор всех сдвигов (С).
- **morse-code** — звук (С); автоопределение направления (Н).
- **password-generator** — фразы из слов (С, словари тяжёлые); несколько паролей (Н).
- **uuid** — больше 50, скачать .txt (Н); разбор UUID (Н).

## images
- **compress-image** — сравнение до/после (В, средняя); «сжать до N КБ» (С); PNG с потерями (отложить).
- **convert-image** — ок.
- **resize-image** — точно W×H с обрезкой (С).
- **heic-to-jpg** — дата съёмки (Н).
- **exif** — HEIC/PNG/WebP (С); все теги (Н).
- **image-to-base64** — URL-кодированный SVG data URL (Н).
- **qr-generator** — предупреждение о контрасте/инверсии (С); e-mail, телефон, vCard (С); размер PNG (Н).
