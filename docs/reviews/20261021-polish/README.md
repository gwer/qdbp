# Причёсывание инструментов (ночь на 2026-10-21)

Задача пользователя: не новые инструменты, а доработка существующих — практичность, удобство, графики/схемы,
сравнение с аналогами. Пример: графики накопления у сложного процента; досрочные погашения — несколько, а не одно.

- `audit-*.md` — аудит по разделам (субагенты читали код и смотрели аналоги; что смотрели вживую, а что по памяти — указано в отчётах).
- `log.md` — что сделано, по инструментам, и что сознательно не сделано.
