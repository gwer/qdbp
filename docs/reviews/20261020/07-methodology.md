## Уровни проверки

1. **Открытие страницы:** все 536 маршрутов в браузере, ожидание гидратации, базовое состояние; два viewport. Это подтверждает доступность и стартовую работу, но не математическую правильность каждого поля.
2. **Эталон расчёта:** 53 сценария для всех 52 Calculator-инструментов; известные математические результаты, календарные границы, нулевые ставки и простая геометрия. 52 совпали, один выявил несогласованность возраста 29 февраля. Тестовая таблица содержит входы, ожидаемые и фактические значения.
3. **Браузерные взаимодействия:** все 96 инструментов охвачены изменённым вводом либо реальным файловым/генеративным действием. В `browser-checks.json` 116 записей: 101 положительная, 15 диагностических несовпадений. Последние не равны 15 отдельным дефектам: есть дубли одного класса и продуктовые ожидания, например одноэлементный жребий. Отдельно 15 файловых сценариев, 12 положительных и 3 воспроизводимых проблемы.
4. **Пограничные проверки:** индивидуальные min/max/select, нечисловой/пустой ввод, совместимость полей, большой список, точность дробей по независимому BigInt-эталону, JSON outside-safe-integer, DST и отрицательные номера дней.
5. **Контент/SEO:** полный структурный проход словарей/статей, смысловая проверка методов, примеров и ограничений, сопоставление найденных проблем в пяти локализациях; проверка HTML-метаданных и sitemap. Это не медицинская, юридическая и не построчная корректорская экспертиза носителей всех языков.
6. **Дополнительная языковая вычитка:** после отдельного вопроса владельца прочитаны все 471 статьи, 471 словарь инструмента, 60 словарей категорий и 5 общих UI-словарей. Грамматика, естественность, точность терминов и смысл; 138 предложений в 114 исходных файлах, из них 9 необязательных P3. Результат — [09](09-language-proofreading.md), `evidence/language-proofreading-{en,ru,es,de,pt}.md` и `evidence/language-proofreading.json`; покрытие с SHA-256 — `evidence/language-coverage-{en,ru,es,de,pt}.json`. `copy-read.mjs` извлекает тексты для чтения; `copy-review.mjs` проверяет исходные фразы и параметры и формирует предложения. Это ИИ-редактура всего перечисленного корпуса, не независимая вычитка носителями. Исходники и обслуживаемая сборка не менялись; повторный браузерный проход после применения предложенных текстов не проводился, поскольку они ещё не применены.

`node scripts/check-dist.mjs`: пройдено. В выводе 663 файла dist, проверены опубликованные URL, внутренние ссылки и заданные бюджеты отдельных файлов. Крупнейший обычный JS — 11,8 KB gzip; крупнейшие HTML — около 11,6 KB gzip. Вывод отдельно не является Lighthouse или полевой проверкой CWV.

## Файловые проверки

Синтетические PNG/JPEG созданы в canvas, без пользовательских фотографий. Размер 800×600; есть прозрачная область, цветные детали и JPEG с приватным тестовым COM-комментарием. После операций проверялись MIME, декодируемость, размерность, отдельные пиксели, байты и SHA-256.

Реальный HEIC взят из публичного тестового примера проекта libheif: [example.heic](https://github.com/strukturag/libheif/blob/master/examples/example.heic). Это внешний тестовый образец, не фото пользователя; ссылка относится к источнику образца, не к юридическому заключению о его дальнейшем распространении. Декодирован в JPEG 1280×854. Декодер и WASM загружались с локального origin.

QR с Unicode и Wi-Fi генерировались в самом сервисе, скачанный PNG прочитан независимым jsQR. ZIP распакован и проверено число записей/имена. COM из результата EXIF реально удалён. GPS/ICC/ориентация проверялись существующими unit-тестами; собственный браузерный EXIF-сценарий использовал COM, а не полный набор метаданных.

Наблюдаемые скачивания перехватывались тестовой обвязкой, содержимое Blob сохранялось в evidence для проверки. Это подтверждает сформированный результат; поведение нативного диалога скачивания на физических мобильных устройствах не исследовалось.

## Приватность и сеть

В полном обходе и файловых сценариях не зафиксировано сторонних запросов от локальной страницы. Вычисления и файлы обрабатывались локально. Вместе с тем отдельный сценарий подтвердил передачу weight/height в адресе document GET после reload.

После уточнения продуктовой границы сохранение расчётов в URL принято как штатное поведение, F01 снят с функциональных дефектов. Основное обещание privacy-first — файлы не загружаются на сервер. Сырые протоколы сохранены без изменений: они фиксируют наблюдение, а не его приоритет. Аналогично подтверждённое округление чисел в JSON остаётся в протоколе, но F04 теперь P2: стандарт допускает ограничения точности реализации; достаточно сначала предупредить пользователя.

Отсутствие внешних запросов на localhost не доказывает отсутствие production-аналитики, CDN-логирования и внешних вставок. Документация проекта упоминает Cloudflare Web Analytics; реальные настройки production в этом ревью не инспектировались. Переход к OpenStreetMap из EXIF — явное действие пользователя, оно не выполнялось с личными координатами.

## Воспроизведение обвязки

Скрипты лежат рядом с отчётами. Они предназначены для этого локального окружения, не установлены в проект как CI/E2E suite. Требуются Node 22, установленный Google Chrome и доступный puppeteer-core; путь к последнему в `audit.mjs` взят из уже существовавшей локальной установки. Для другого компьютера его нужно адаптировать. Зависимости приложения не менялись.

Основные команды из этой директории:

```sh
node audit.mjs inventory
node audit.mjs crawl
node inspect-runtime.mjs
node compute-checks.mjs
node browser-checks.mjs
node image-checks.mjs
node layout-seo-checks.mjs
node corpus-audit.mjs
node slug-checks.mjs
```

`browser-checks.mjs --resume` продолжает существующий протокол; для чистого повторного прогона запускать без `--resume`. Скрипт `image-checks.mjs` требует `evidence/example.heic`, который уже сохранён. Загружать пользовательские файлы для воспроизведения не нужно.

`ts-loader.mjs` транспилирует TS/TSX и разрешает alias исходников для проверки чистых вычислений. URL-импорты бинарных ассетов в нём заменены неиспользуемыми строками: это только позволяет загрузить определения; сам HEIC и файловые операции тестировались отдельно в реальном браузере с настоящими ассетами. Не использовать этот loader как замену production build.

## Границы заключений

- Chrome — единственный реально запущенный браузерный движок. Мобильный viewport не заменяет iOS Safari и Android с реальной клавиатурой/памятью.
- Не перебраны все возможные значения и режимы каждого инструмента. Матрица 02 показывает конкретное покрытие и следующие полезные проверки.
- Не проводились нагрузочная атака, проникновение в инфраструктуру, исследование серверных логов, полная проверка лицензий и клиническая/налоговая экспертиза всех текстов.
- Не измерены реальные позиции, спрос, backlinks, доход и CWV. Не инспектировались панели владельца и production-инъекции.
- На простых положительных сценариях сервис работает; найденные дефекты не следует распространять на все операции. При этом зелёные unit-тесты не отменяют подтверждённые ошибки.
