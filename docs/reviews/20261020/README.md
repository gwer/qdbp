## Самое существенное

1. **Компрессор может вернуть исходный файл вместе с метаданными.** Подтверждено сохранение приватного JPEG-комментария; файл совпадает с исходным побайтно. F02.
2. **ZIP может молча потерять результат при коллизии имён.** Три обработанных файла превращаются в два файла архива. F03.
3. **Большие дроби могут давать неверный точный результат.** Калькулятор теряет точность промежуточных произведений. F05.
4. **Есть ошибки календарной логики.** 29 февраля, весенний DST в Нью-Йорке, будние дни и номера недель до 1970 года. F06–F08.
5. **Контент требует предметной правки.** Неверная инструкция про trade-in в EN, неподдерживаемый cash-out, несовпадающая EN-формула жира, обещания про подсчёт слов, формулировки медицинских рекомендаций. C02–C11.

После уточнения продуктовой границы F01 снят с функциональных дефектов: состояние калькулятора в URL — принятое поведение. Privacy-first прежде всего означает обработку файлов без загрузки на сервер; уточнение текста подвала вынесено в C01 (P2). F04 понижен до P2: большие числа допустимы в JSON, но JavaScript Number имеет разрешённые стандартом ограничения точности. Первый достаточный шаг для форматтера — предупреждение, а не обязательная замена парсера.

P0 — недоступность сервиса или сопоставимая авария — в проверенном окружении не обнаружен. P1 в отчётах означает необходимость исправить до масштабного продвижения соответствующего инструмента; P2 — ближайшая очередь; P3 — улучшение.
